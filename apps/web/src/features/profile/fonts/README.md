# Fonts

Both fonts are open source under the SIL Open Font License 1.1 and are bundled here so the screens look the same offline.

- `caprasimo-latin-400-normal.woff2`: Caprasimo (Latin), by the Caprasimo Project Authors. A chunky retro display face used for headings, chosen to sit beside the ThirdPlace logo.
- `nunito-latin-wght-normal.woff2`: Nunito (variable weight, Latin), by Vernon Adams and contributors. Used for text.

Files come from the Fontsource packages `@fontsource/caprasimo` and `@fontsource-variable/nunito`.
