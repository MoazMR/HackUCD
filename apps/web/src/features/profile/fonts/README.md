# Fonts

Both fonts are open source under the SIL Open Font License 1.1 and are bundled here so the screens look the same offline.

- `nunito-latin-wght-normal.woff2`: Nunito (variable weight, Latin), by Vernon Adams and contributors. Used for headings and text.
- `caveat-latin-700-normal.woff2`: Caveat Bold (Latin), by Impallari Type. Used for the handwritten script.

Files come from the Fontsource packages `@fontsource-variable/nunito` and `@fontsource/caveat`.
